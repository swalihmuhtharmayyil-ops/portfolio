# Swalih Muhthar — AI Educator Portfolio

A responsive, static portfolio website built with **HTML + CSS + vanilla JavaScript**. No build step and no framework are required.

## Included effects

- Floating / layered folder-style project effect
- Expandable profile card
- Adaptive curriculum slider
- Drag/swipe project cards
- Vertical carousel navigator
- Bento project layout
- Hero parallax effect
- Scroll reveal animations
- Responsive mobile layout
- Reduced-motion accessibility support

## Run locally

Open `index.html` directly, or use a local server for the cleanest experience:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy to GitHub Pages

1. Create a GitHub repository, e.g. `swalih-portfolio`.
2. Upload all files in this folder.
3. Go to **Settings → Pages**.
4. Set the source to the `main` branch and `/root`.
5. Save and wait for GitHub Pages to publish.

## Deploy to Vercel / Netlify

Import the repository as a static site. There is no build command and no output directory required.

## Important

The `docs/` folder contains the curriculum and trainer-session PDFs supplied for this portfolio. If the GitHub repository will be public and these documents are not intended for public distribution, remove them before pushing and keep them private.
